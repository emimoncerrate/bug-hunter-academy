# Bug Hunter Academy

A self-paced debugging lesson for high school computer science (ELL / IEP friendly).

- **Training:** 5 short missions — the 4 debugging steps, indentation, motion (x, y, + and −), operators (< > =) and sensing & collision. One step on screen at a time.
- **Bug Arcade:** 5 broken arcade games (Dino Run, Dot Chase, Space Defenders, Paddle Ball, Road Hopper), 3 bugs each, fixed in a drag-and-drop block editor styled after Dino Run.
- English / Spanish toggle and read-aloud on every screen.

It is a static site: open `index.html`, or host the folder on any static host. Progress is saved in each student's browser.

Files: `index.html` (page + styles), `engine.js` (block engine and editor), `games.js` (games, sandboxes, puzzles), `app.js` (lesson content and pages), `dino-world.jpg` (Dino Run map image).
